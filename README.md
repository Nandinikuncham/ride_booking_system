# Ride Booking System (Uber-like)

A simplified Uber-like ride booking system built to understand **real-world backend systems**, **API design**, and **frontend–backend integration**.

This project simulates the complete ride lifecycle — from requesting a ride to assigning a driver, calculating fare, and completing the ride — using RESTful APIs and an interactive frontend.


## Features

- Request a ride with destination and vehicle type
- Dynamic driver assignment based on availability
- Fare calculation logic
- Ride lifecycle management (ASSIGNED → COMPLETED)
- Ride history per user
- Interactive frontend using vanilla JavaScript
- Proper error handling and validation


## Tech Stack

**Backend**
- Python
- FastAPI
- REST APIs
- Uvicorn

**Frontend**
- HTML
- CSS
- JavaScript (Fetch API)
